## 📖 Descripción

**GANSTA HIDALGO** es una plataforma web e-commerce completa diseñada para la venta de gorras de calidad 1:1, fragancias importadas y la gestión de sorteos con premios en efectivo. 

El sitio incluye un sistema de boletos numerados con bloqueo automático para evitar duplicados, múltiples métodos de pago (WhatsApp, PayPal, PayPal.me) y un panel de administración protegido para gestionar pedidos y realizar sorteos automáticos.

---

## ✨ Características Principales

### ️ E-Commerce
- ✅ Catálogo completo de **Gorras Calidad 1:1** (9 modelos)
- ✅ Catálogo de **Fragancias Importadas** (9 perfumes)
- ✅ Carrito de compras funcional
- ✅ Envío de pedidos directo a WhatsApp

### 🎰 Sistema de Sorteos
- ✅ **100 boletos numerados** por sorteo
- ✅ **Bloqueo automático** de boletos vendidos (evita duplicados)
- ✅ Selección manual o aleatoria de boletos
- ✅ **Sorteo automático** con animación de ruleta
- ✅ Reporte del ganador enviado por WhatsApp

###  Métodos de Pago
- 📱 **WhatsApp** - Transferencia / Depósito
- 🅿️ **PayPal** - Pago seguro con checkout
- 💸 **PayPal.me** - Pago rápido con link personalizado

### 👑 Panel de Administración
- 🔐 Acceso protegido con contraseña
- 📊 Estadísticas en tiempo real (ventas, pedidos, recaudación)
-  Lista completa de pedidos recibidos
-  **Reinicio selectivo** de boletos individuales
- 🗑️ Reinicio total del sistema
- 🎯 Selector de sorteo para realizar automáticamente
